ESP32 · Open source

ESP32 Function Generator

A five-channel signal generator for the classic ESP32. Configure three complementary PWM pairs with adjustable duty and dead time, plus two multifunction outputs for pulses, bursts, and analog waveforms.

Control it over Wi-Fi, through a USB browser interface, or with the Python desktop app.

Python desktop app · Open source

OpenCaliper

A measurement data viewer and analysis tool for Windows and Linux. Open recorded signals, compare them in plots, measure with differential cursors, and explore FFT spectra and statistics.

Import and convert supported measurement formats, with a desktop interface, command-line tools, and a Python API.
